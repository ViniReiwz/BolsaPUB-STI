# BolsaPUB-STI
Este repositório sumariza tudo que contribuí dentro do contexto do STI (Seção Técnica e Informática) da EESC, no perído de vigência da bolsa PUB.

- [Equivalência de disciplinas](https://github.com/ViniReiwz/equivalencia): Aplicação para a informatização de equivalência de disciplinas na USP;  

- [Biblioteca de Workflow](https://github.com/ViniReiwz/workflow): Biblioteca geradora de fluxos de trabalho dinâmico através de uma definição estruturada;  

- [Biblioteca de Formulário](https://github.com/ViniReiwz/forms):  Biblioteca geradora de formulários dinâmicos através de definições estruturadas;  

- [Aplicação de teste para a biblioteca de Workflow](https://github.com/ViniReiwz/Workflow_Teste).
